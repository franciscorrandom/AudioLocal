AudioLocal 1.0.0-beta.1 para Windows
GuiaEstudio — https://guiaestudio.cl/audiolocal/

Requisitos: Windows 10 u 11 de 64 bits, internet y espacio para tus audios.
Incluye Python, Tk, Node, yt-dlp y FFmpeg; no debes instalarlos por separado.

INSTALADOR
1. Abre AudioLocal-1.0.0-beta.1-Windows-x64-Setup.exe.
2. Instala para tu usuario y abre AudioLocal desde el menú Inicio.
No requiere permisos de administrador. El desinstalador conserva tus MP3.

VERSION PORTATIL
1. Extrae completamente AudioLocal-1.0.0-beta.1-Windows-x64.zip.
2. Abre AudioLocal.exe dentro de la carpeta extraída.
Conserva la carpeta _internal junto al ejecutable. No abras dentro del ZIP.

USO
Pega un enlace individual de YouTube por línea. Elige calidad 128, 192 o
320 kbps y pulsa Descargar. Puedes cambiar la carpeta de salida, abrirla o
cancelar. Los MP3 ya terminados se conservan. Los audios existentes nunca
se sobrescriben. De forma inicial guarda en Descargas/AudioLocal.

La beta no está firmada digitalmente. Windows puede mostrar el aviso de
SmartScreen al abrir un programa nuevo: verifica que proviene de GuiaEstudio.
No necesitas desactivar el antivirus ni la protección de Windows.

YouTube puede cambiar sus requisitos o rechazar algunos videos. Las futuras
actualizaciones se publicarán en la página de AudioLocal. La beta no instala
actualizaciones automáticas. Usa únicamente contenido que puedes descargar.

Las licencias de las herramientas incluidas están en _internal/licenses.
El código fuente y las fuentes de las dependencias están disponibles como
AudioLocal-1.0.0-beta.1-Windows-Fuentes.zip en la misma publicación GitHub.
